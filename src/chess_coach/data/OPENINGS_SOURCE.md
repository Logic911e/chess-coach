# openings.tsv

The ECO code, name and move list of about 3,900 chess openings, taken unchanged from
https://github.com/lichess-org/chess-openings (files a.tsv to e.tsv, joined under one header).
The data is released under CC0 (public domain). It is used only to put a name on a stored game;
see `src/chess_coach/openings.py`.
